# 个人中文网文人工质感修订工具包

这是一个从个人中文网文《停在十七岁的人》的长期修订现场里制作出来的工具包，用来把机器味、模板味、概括味过重的草稿，修成更像个人作者长期写出来的文本。

项目不以“规避 AI 检测”为目标，也不承诺让文本通过任何检测器。它关注的是个人长篇网文写作里更扎实的修订问题：人物是否贴身，台词是否像活人说话，连续性是否咬合，重复表达是否失控，情绪是否由动作和物件承重，而不是由解释腔替读者下结论。

## 项目目标

- 把一个个人中文网文项目里的修订经验，沉淀成可复用的个人审稿流程。
- 帮助个人作者定位“AI 感”常见来源：抽象总结、客观镜头漂浮、台词过完整、情绪解释、段落节奏单一、跨章复用痕迹。
- 用脚本和规则库辅助作者本人修稿，而不是替代作者判断。
- 支持个人长篇小说的卷级连续性修订、单章审稿、跨章风格一致性检查。

## 当前来源

本工具包从个人中文网文《停在十七岁的人》的长期修订流程中抽象而来。它首先服务这一本小说，再把其中不依赖专名的部分整理成可复用资产：

- 语感事后审计：动作短句、活人对白、情绪物件承重。
- 重复表达扫描：硬禁句、全章频率、千字频率、两千字频率。
- 跨章复用扫描：检查相邻章节或远距离章节中的模板化表达回流。
- 连续性预检：上章咬合、角色状态、地点移动、物资与战损。
- 章事实卡、时间线、伏笔表、角色状态表：为长篇修订提供事实底座。

## 适用文本问题

### 1. 客观镜头漂浮

常见表现：

- “有人喊了一声”“所有人都僵住”“空气安静下来”这类概括句过多。
- 场景看似宏大，但没有贴住具体人物的手、脚、呼吸、疼痛、犹豫。
- 段落像摄影机横移，而不是角色在场。

修订方向：

- 每个高压段落至少有一个贴人锚点。
- 用具体动作、身体反应、物件位置接住情绪。
- 把概括人声改成能听见的现场语言。

### 2. 台词问答题感

常见表现：

- 角色总是正面回答问题。
- 台词信息密度很高，但缺少打断、迟疑、抢话、嘴硬。
- 每个人说话口气接近，像同一个叙述者在分配信息。

修订方向：

- 增加非正面回应、半句话、动作压台词。
- 让不同角色有不同的避让方式和表达习惯。
- 用场景压力打断台词完整性。

### 3. 情绪解释腔

常见表现：

- “他终于明白”“这意味着”“她很痛苦”之类解释句过多。
- 情绪直接被命名，而没有落到物件、动作、沉默和位置关系。

修订方向：

- 先让物件承重，再允许少量直白判断。
- 把“悲伤/坚定/崩溃”拆成手上动作、视线停顿、话没说完。
- 保留读者自己判断的空间。

### 4. 长篇连续性松动

常见表现：

- 伤势、异能代价、物资消耗、空间移动在跨章后自动归零。
- 上一章刚形成的关系裂缝，下一章突然消失。
- 卷级分镜变化后，旧稿素材误进入新逻辑。

修订方向：

- 写作前先读取章事实卡、时间线、角色状态和上章出口。
- 卷级修订优先处理硬连续性，再处理人物线、编号、文风降噪。
- 旧稿只作为素材池，不直接继承旧结构。

## 最小工作流

1. 输入单章草稿或卷级稿件。
2. 读取写作规则库、章节事实卡和时间线。
3. 运行重复表达扫描。
4. 运行语感事后审计。
5. 运行跨章复用和连续性预检。
6. 输出“必须处理 / 建议处理 / 人工复核”三层报告。
7. 作者本人根据报告改稿。
8. 改后再次审计，直到硬问题归零。

## 项目边界

- 不做 AI 检测器。
- 不提供规避平台检测、伪装作者身份或洗稿服务。
- 不替作者重写整本书的声音，也不把个人创作包装成团队生产线。
- 不把“更像人写”简化成随机加错别字、加口语、加废话。

真正的人工质感来自具体经验、稳定记忆、角色账本、长期取舍和可追溯修订。
